## Repository scope

The federated learning experiments evaluated in the manuscript were conducted using FedEMR.ai, a separately developed federated learning research platform used to coordinate distributed model training across participating clinical sites while patient-level source data remain within the participating institutions.

The federated learning methods, algorithm configurations, model training procedures, and experimental design used in the study are described in the Methods section of the associated manuscript.

This repository contains the downstream benchmark analysis code used to generate the manuscript tables, figures, and statistical analyses. It does **not** contain the FedEMR.ai platform source code, federated learning orchestration software, deployment infrastructure, or the platform implementation used to execute the federated learning algorithms. Those components are proprietary and are outside the scope of this manuscript analysis repository.

The analysis scripts operate on outputs generated by completed federated learning experiments, including, as applicable:

- the selected global model output from each federated learning run;
- model performance metrics recorded across federated learning communication rounds; 
- derived model-level and run-level results required for the manuscript analyses.

**No patient-level clinical data are included in this repository.**

References to FedAvg, FedAvgM, FedProx, XGBoost, or other methods in file names or analysis scripts identify the experimental conditions being analyzed. They do not constitute a release or reimplementation of the FedEMR.ai platform or its federated learning engine.

## Directory descriptions

### `condition_specific_analysis/`

Contains the primary analysis scripts for the individual benchmarking conditions evaluated in the manuscript.

These include:

- logistic regression (`lr`) analyses using FedAvg, FedAvgM, and FedProx;
- multilayer perceptron (`mlp`) analyses using FedAvg, FedAvgM, and FedProx;
- XGBoost histogram aggregation and tree sharing analyses; 
- the script used to generate Table 1.

These scripts serve as analysis entry points for the corresponding experimental conditions.

### `combined_analysis/`

Contains scripts that combine results across experimental conditions to generate cross-condition manuscript outputs, including:

- fidelity and recovery analyses;
- transportability analyses; 
- total training-time summaries.

### `functions/`

Contains reusable functions called by the analysis scripts.

- `common/` — functions shared across analyses;
- `lr/` — logistic-regression-specific analysis functions;
- `mlp/` — multilayer-perceptron-specific analysis functions;
- `xgb/` — XGBoost-specific analysis functions;
- `executor` — the main analysis function that calls and coordinates the supporting functions within the package;
- `__init__` — package initialization.

---

## Analysis inputs

The analysis scripts use model-level and run-level outputs generated by the federated learning experiments rather than patient-level source data.

Depending on the analysis, these inputs include:

- selected global model outputs;
- model performance metrics from individual federated learning communication rounds; 
- derived run-level summary outputs.

These files represent outputs of the completed experiments and do not contain patient-level clinical records.

---

## Reproducibility boundary

This repository is intended to support transparency, inspection, and reproducibility of the downstream benchmark analyses reported in the manuscript.

Specifically, it provides the code used to transform federated learning experiment outputs into the manuscript's:

- tables;
- figures;
- statistical comparisons; 
- summary measures.

The repository is **not** a distribution of FedEMR.ai and is not intended to independently reproduce the underlying federated learning platform, orchestration layer, distributed deployment infrastructure, or proprietary platform implementation.

The methodological details required to understand the federated learning experiments, including the evaluated methods, configurations, training procedures, and experimental design, are described in the associated manuscript.
